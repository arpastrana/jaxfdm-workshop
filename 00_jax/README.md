# 00 — A JAX primer

A short notebook, not a JAX course. It covers the few ideas the rest of the
workshop uses: `jax.numpy`, arrays with a meaningful shape, `vmap`, `grad`, and
`jacobian`.

Open `jax_primer.ipynb` in Cursor and run all cells. If the notebook kernel asks
for an interpreter, pick the workshop `.venv`.

Or, from a terminal:

```bash
uv run jupyter lab jax_primer.ipynb
```
